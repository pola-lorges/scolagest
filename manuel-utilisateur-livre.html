Manuel fonctionnel détaillé

Bien utiliser
ScolaGest

Le guide pas à pas des opérations scolaires, de l’inscription d’un élève au suivi des frais et à l’édition des documents.

Pour les équipes administratives et pédagogiquesVersion correspondant aux fonctions actuellement publiées
Comment lire ce guide

Avant de commencer

Ce manuel explique ce que l’on peut faire dans ScolaGest, où trouver les commandes, quelles informations saisir et ce qui se passe après chaque action. Chaque chapitre suit les écrans de l’application et nomme les boutons tels qu’ils apparaissent.

Les commandes de création, de modification et de suppression ne sont disponibles que si le compte possède les autorisations nécessaires. Quand une suppression est définitive ou qu’une action a un effet important, le guide le signale.

Limite actuelle des comptes : le parcours de connexion publié accepte les comptes administrateurs. Les rôles Enseignant, Parent, Élève et Administration sont présents dans l’application, mais leur connexion n’est pas actuellement activée. Créer un compte non administrateur ne suffit donc pas à lui donner un accès fonctionnel.
Principe de travail : vérifiez d’abord l’année scolaire, la classe et l’identité de la personne concernée. Après une saisie importante, relisez le résultat à l’écran avant de poursuivre.
Chapitre 1

Se connecter et se repérer

Ouvrir une session

  1. Ouvrez l’adresse de ScolaGest dans votre navigateur.
  2. Dans Code de l’établissement, saisissez le code fourni par l’administrateur.
  3. Dans Adresse e-mail, saisissez l’adresse du compte administrateur.
  4. Dans Mot de passe, saisissez le mot de passe du compte.
  5. Cliquez sur Se connecter.

Si la connexion échoue, relisez le code et l’adresse e-mail, puis vérifiez le mot de passe avec l’administrateur. Le message affiché dans le formulaire indique si les identifiants ou l’accès à l’établissement sont refusés.

Se déplacer dans l’application

  1. Utilisez les liens du menu latéral pour ouvrir un module : Élèves, Classes, Notes, Paiements, etc.
  2. Le titre en haut de page indique le module ouvert.
  3. Le bandeau d’année scolaire rappelle l’année et le trimestre courants.
  4. Sur un téléphone ou une petite fenêtre, cliquez sur ☰ pour ouvrir ou fermer le menu.
  5. Cliquez sur 🌙 ou ☀️ pour changer le thème.
  6. Cliquez sur 🚪 pour quitter la session.
Résultat : les écrans accessibles s’affichent selon le compte connecté. Un module non autorisé présente un message indiquant que les droits sont insuffisants.
Chapitre 2

Préparer les données de l’établissement

Pour éviter les fiches orphelines et les erreurs de classement, construisez d’abord les éléments de référence, puis ajoutez les personnes et enfin les opérations quotidiennes.

  1. Ouvrez Paramètres et enregistrez le nom, l’année scolaire, la période en cours et le logo.
  2. Ouvrez Classes et créez les classes avec leur niveau, leur capacité et leur année.
  3. Ouvrez Enseignants et créez les fiches des membres du personnel.
  4. Ouvrez Matières, définissez les matières et les coefficients.
  5. Dans chaque classe, affectez les matières et les enseignants.
  6. Ouvrez Élèves et ajoutez les élèves à leur classe.
  7. Commencez ensuite la saisie des notes, absences, paiements et documents.
Pourquoi cet ordre ? Les formulaires d’élève proposent les classes existantes; les notes s’appuient sur les matières affectées; les bulletins utilisent les notes et les coefficients déjà enregistrés.

Les identifiants à stabiliser

Attribuez un matricule unique à chaque élève et enseignant. Gardez une orthographe stable pour les noms des élèves, classes et matières, notamment lors d’importations CSV ou de recherches ultérieures.

Chapitre 3

Lire le tableau de bord

Le tableau de bord est une synthèse. Il sert à repérer rapidement les effectifs et les principaux indicateurs, pas à remplacer les listes détaillées des modules.

Les indicateurs visibles

  • Élèves inscrits : nombre total de fiches d’élèves.
  • Classes : nombre de classes créées.
  • Enseignants : nombre de fiches d’enseignants.
  • Absents aujourd’hui : absences d’élèves enregistrées pour la date du jour.
  • Total encaissé : somme des versements enregistrés.
  • Reste à recouvrer : différence calculée entre les montants dus et payés.

Les tableaux en dessous présentent la répartition des élèves par statut et les effectifs par classe, avec comparaison à la capacité.

Un chiffre paraît faux ? Ouvrez le module concerné et contrôlez les fiches sources : statut de l’élève, classe de rattachement, année du dossier de paiement et versements enregistrés.
Chapitre 4

Gérer les élèves

Retrouver une fiche

  1. Ouvrez Élèves.
  2. Saisissez un nom, un prénom ou un matricule dans Rechercher nom, matricule….
  3. Utilisez Toutes les classes pour limiter la liste à une classe.
  4. Utilisez Tous statuts pour filtrer les élèves actifs, transférés, exclus ou diplômés.
  5. Pour revenir à la liste complète, effacez le texte et remettez les filtres à leur valeur générale.

Créer une fiche complète

  1. Cliquez sur + Nouvel élève.
  2. Ajoutez une photo si vous en avez une.
  3. Remplissez Matricule, Prénom et Nom. Ces trois informations sont obligatoires.
  4. Choisissez le statut, le sexe et renseignez la date et le lieu de naissance si connus.
  5. Choisissez la classe et vérifiez l’année scolaire proposée.
  6. Ajoutez l’adresse et les coordonnées du parent ou responsable légal.
  7. Cliquez sur Enregistrer.

Si le matricule existe déjà, l’application refuse la fiche pour éviter un doublon. Choisissez un matricule unique avant de réessayer.

Consulter, modifier ou supprimer

  • 👁️ ouvre le profil : identité, coordonnées, statut et historique des classes; Fermer quitte le profil.
  • ✏️ ouvre le formulaire de modification; vérifiez les changements puis enregistrez.
  • 🗑️ demande confirmation. La suppression est définitive; vérifiez qu’il ne s’agit pas d’un élève encore suivi.

Importer et exporter la liste

  • ⬇️ Export CSV télécharge la liste correspondant aux filtres actifs.
  • ⬆️ Import CSV ouvre le sélecteur de fichier. Choisissez un fichier CSV préparé à partir des colonnes attendues par l’application.

Avant l’import, vérifiez les matricules, l’année et l’orthographe des classes. Les matricules déjà présents sont ignorés; un nom de classe non reconnu peut laisser une fiche sans classe. Après l’import, recherchez plusieurs élèves et contrôlez leurs fiches.

Chapitre 5

Créer et organiser les classes

Créer une classe

  1. Ouvrez Classes et cliquez sur + Nouvelle classe.
  2. Saisissez le nom de la classe et le niveau; ces deux champs sont obligatoires.
  3. Renseignez la capacité maximale et l’année scolaire.
  4. Choisissez le professeur principal si cette information est connue.
  5. Pour chaque matière affichée, sélectionnez l’enseignant qui y est affecté.
  6. Cliquez sur Enregistrer.

Une capacité vide ou égale à zéro revient à 40. Une classe qui dépasse sa capacité est signalée dans la liste; ce signalement n’interdit pas automatiquement l’inscription d’un élève.

Ouvrir le détail d’une classe

  1. Cliquez sur la carte de la classe.
  2. Consultez la liste des élèves, leur matricule, sexe et statut.
  3. Consultez les matières, coefficients et enseignants associés.
  4. La ligne du professeur principal et les enseignants de la classe apparaissent sous les tableaux.
  5. Cliquez sur ← Toutes les classes pour revenir aux cartes.

Ajouter un élève depuis le détail

  1. Cliquez sur + Élève.
  2. Renseignez nom, prénom et matricule; ils sont obligatoires.
  3. Choisissez le sexe et complétez, si possible, naissance et coordonnées du parent.
  4. Cliquez sur Ajouter.

Ce formulaire rapide fixe automatiquement le statut à actif et rattache l’élève à la classe ouverte. Pour ajouter photo, adresse ou e-mail, utilisez ensuite la fiche complète du module Élèves.

Affecter un professeur et une matière

  1. Cliquez sur + Professeur / matière.
  2. Choisissez une matière existante ou choisissez + Nouvelle matière….
  3. Pour une nouvelle matière, saisissez son nom et son coefficient (1 par défaut).
  4. Choisissez un professeur existant ou + Nouveau professeur….
  5. Pour un nouveau professeur, renseignez son nom et son prénom; téléphone et e-mail sont facultatifs.
  6. Cliquez sur Ajouter.

L’affectation remplace l’enseignant déjà lié à cette matière dans cette classe. Le professeur et la matière nouvellement créés peuvent être utilisés dans les autres formulaires.

Produire les fiches vierges

  • 📋 Fiche de présence : choisissez éventuellement une matière, une période et un nombre de colonnes (1 à 31, 20 par défaut), puis téléchargez la fiche PDF paysage.
  • 📝 Fiche de notes : choisissez matière, évaluation et barème (20 par défaut), puis téléchargez la fiche PDF portrait.

Une classe sans élève ne produit pas de fiche utilisable. Vérifiez la classe et son effectif avant de lancer le téléchargement.

Modifier ou supprimer une classe

✏️ Modifier rouvre le formulaire de classe. 🗑️ demande confirmation. Les élèves ne sont pas supprimés, mais deviennent sans classe; réaffectez-les si la suppression était accidentelle.

Chapitre 6

Gérer les enseignants

Rechercher et consulter

  1. Ouvrez Enseignants.
  2. Dans Rechercher un enseignant…, tapez son nom ou son matricule.
  3. Consultez dans la liste matricule, matières, classes et téléphone.
  4. Cliquez sur 👁️ pour ouvrir le profil détaillé.

La fiche détaillée regroupe les coordonnées, matières, classes, emploi du temps et absences/retards enregistrés. Pour la refermer, cliquez sur Fermer.

Créer un enseignant

  1. Cliquez sur + Nouvel enseignant.
  2. Renseignez prénom, nom et matricule; ils sont obligatoires.
  3. Ajoutez téléphone, e-mail, adresse et photo si disponibles.
  4. Sélectionnez les matières enseignées. Pour sélectionner plusieurs matières, maintenez Ctrl (Windows) ou Cmd (Mac) pendant les clics.
  5. Cliquez sur Enregistrer.

Le matricule doit être unique. Les boutons ✏️ et 🗑️ permettent de modifier ou de supprimer une fiche; la suppression doit être confirmée. Elle ne propose pas de retirer automatiquement toutes les affectations existantes.

Chapitre 7

Définir les matières

Une matière indique ce qui est enseigné, le coefficient utilisé dans les calculs, le niveau concerné, le programme éventuel et l’enseignant responsable.

Créer une matière

  1. Ouvrez Matières et cliquez sur + Nouvelle matière.
  2. Saisissez le nom et un coefficient supérieur à zéro. Ces champs sont obligatoires.
  3. Complétez le niveau, le programme et l’enseignant responsable si connus.
  4. Cliquez sur Enregistrer.

La liste permet de repérer le coefficient, le niveau, l’enseignant et les classes liées. Utilisez ✏️ pour modifier. 🗑️ supprime la matière après confirmation; examinez d’abord ses usages dans les classes et évaluations.

Chapitre 8

Saisir, importer et vérifier les notes

Choisir la bonne période

Le module Notes propose les trimestres et séquences suivants :

TrimestreSéquences
Trimestre 1Séquence 1, Séquence 2
Trimestre 2Séquence 3, Séquence 4
Trimestre 3Séquence 5

Utiliser la saisie en tableau

  1. Ouvrez Notes. Si vous avez les droits de saisie, choisissez l’onglet ✍️ Saisie des notes.
  2. Dans Classe, choisissez la classe concernée.
  3. Choisissez Trimestre, puis Séquence.
  4. Choisissez un élève ou Tous les élèves, puis la Matière.
  5. Choisissez une Évaluation, sa catégorie pour le bulletin et le Barème.
  6. Saisissez une valeur par élève dans la grille. Entrée ou la flèche vers le bas passe à l’élève suivant.
  7. Cliquez sur 💾 Enregistrer les notes.

Les valeurs en saisie groupée doivent être comprises entre zéro et le barème. Une note laissée vide peut empêcher l’enregistrement de la série; complétez les cases ou corrigez votre sélection avant de recommencer.

Créer un type d’évaluation

  1. Cliquez sur + Nouvelle évaluation.
  2. Saisissez un nom unique, de 30 caractères maximum.
  3. Choisissez Évaluation harmonisée (70 %) ou Évaluation hebdomadaire (30 %).
  4. Enregistrez, puis sélectionnez le nouveau type pour la saisie.
Attention à la corbeille près du type : elle supprime ce type d’évaluation et toutes les notes associées dans toutes les classes après confirmation. Préférez modifier une note individuelle si seule une valeur est erronée.

Importer une fiche de notes

  1. Cliquez sur 📥 Importer une fiche.
  2. Choisissez un tableur, CSV/TSV/TXT, JSON, PDF, DOCX ou une image contenant les noms ou matricules et les notes.
  3. Suivez les choix d’import proposés pour identifier la classe, la matière, la période, le type d’évaluation et le barème.
  4. Examinez le résumé des élèves reconnus et des lignes non appariées avant de valider.
  5. Après import, filtrez quelques élèves et comparez les notes avec l’original.

Les notes hors barème peuvent être ignorées; les élèves non reconnus sont signalés. PDF, images et DOCX peuvent nécessiter une connexion Internet pour la reconnaissance. Le format Word ancien .doc est refusé.

Consulter et corriger des notes existantes

  1. Cliquez sur 📋 Notes saisies.
  2. Filtrez par classe, trimestre, séquence, élève, matière et évaluation.
  3. Cliquez sur ✏️ à côté de la note à corriger, puis enregistrez la nouvelle valeur.
  4. Cliquez sur 🕓 pour examiner l’historique des modifications.
  5. Cliquez sur 🗑️ et confirmez uniquement si la note ne doit plus exister.

Les classements sont disponibles par trimestre ou par séquence. Les notes sont ramenées sur 20; les catégories harmonisées et hebdomadaires comptent respectivement pour 70 % et 30 % lorsque les deux sont présentes. Le coefficient de chaque matière intervient ensuite dans la moyenne générale.

Chapitre 9

Prévisualiser et produire les bulletins

  1. Ouvrez Bulletins.
  2. Choisissez une Classe, un Trimestre et une Séquence.
  3. Choisissez l’élève concerné.
  4. Cliquez sur 👁️ Aperçu du bulletin pour le contrôler à l’écran.
  5. Choisissez ⬇️ Bulletin séquentiel PDF pour la séquence affichée ou ⬇️ Bulletin trimestriel PDF pour le bilan du trimestre.

Selon les droits, deux commandes supplémentaires produisent un fichier groupé pour la classe : ⬇️ Bulletins séquentiels (classe) et ⬇️ Bulletins trimestriels (classe).

Tableaux d’honneur

🏅 Tableau d’honneur produit le document de l’élève sélectionné s’il atteint le seuil prévu de 12/20. 🏅 Tous les tableaux d’honneur regroupe les élèves de la classe qui atteignent ce seuil. Les félicitations sont associées à partir de 14/20.

Contrôle avant diffusion : vérifiez que les notes de toutes les matières sont saisies, que les coefficients sont corrects et que le trimestre/séquence sélectionné correspond à la période à communiquer. Les appréciations et décisions automatiques doivent être relues par l’équipe éducative.
Chapitre 10

Enregistrer les absences et retards

  1. Ouvrez Absences & Retards.
  2. Choisissez Élèves ou Enseignants.
  3. Pour les élèves, sélectionnez la classe. Choisissez ensuite la date.
  4. Cliquez sur Marquer en regard de la personne concernée.
  5. Choisissez Présent, Absent ou Retard.
  6. Indiquez si l’absence est justifiée, ajoutez le motif et joignez le justificatif si disponible.
  7. Cliquez sur 💾 Enregistrer.

Enregistrer la présence de toute la classe

✅ Marquer tous présents crée les entrées de présence pour les élèves de la classe ou les enseignants sélectionnés à la date courante. L’action ne demande pas de confirmation et efface les motifs existants pour ces entrées; utilisez-la seulement après vérification.

Relire l’historique

La section Historique récent affiche jusqu’à 30 enregistrements récents. Elle n’offre pas de filtre ni de commande de correction/suppression directement dans la liste.

Notification : le message de confirmation relatif à une notification parentale est simulé. Aucun SMS ou e-mail n’est envoyé par cette action.
Chapitre 11

Construire l’emploi du temps

Consulter une classe

  1. Ouvrez Emploi du temps.
  2. Choisissez la classe dans le sélecteur.
  3. Parcourez la grille des jours et heures. Les jours vont du lundi au samedi.

Ajouter un créneau

  1. Cliquez sur + Ajouter un créneau.
  2. Choisissez le jour et indiquez la salle.
  3. Saisissez l’heure de début et l’heure de fin; la fin doit être après le début.
  4. Choisissez la matière et l’enseignant.
  5. Cliquez sur 💾 Ajouter.
  6. Si un conflit de classe, d’enseignant ou de salle est signalé, modifiez l’horaire ou l’affectation avant d’enregistrer.

La commande ✕ sur un créneau le supprime immédiatement, sans confirmation. Aucun bouton de modification n’est proposé : pour corriger un créneau, supprimez-le puis recréez-le.

⬇️ PDF de l’emploi du temps télécharge la grille de la classe en paysage. Le téléchargement est refusé si aucun créneau n’est enregistré.

Chapitre 12

Suivre les frais et les versements

Retrouver une classe

  1. Ouvrez Paiements & Frais.
  2. Saisissez le nom de la classe dans Rechercher une classe…. La recherche porte uniquement sur les classes.
  3. Consultez sur chaque carte le nombre d’élèves, les montants payés, à verser et restant.
  4. Cliquez sur la carte de la classe pour afficher le détail de ses élèves.
  5. Utilisez ← Toutes les classes pour revenir à la grille.

Le détail liste matricule, nom, montant à verser, payé, reste, statut et actions. Les statuts possibles sont Sans dossier, À compléter, Soldé, Partiel et Impayé. Si la fiche de classe et le dossier de paiement ont des années différentes, l’application utilise d’abord le dossier de même année; s’il n’y en a pas, elle affiche le dossier le plus récent.

Les quatre frais obligatoires

Chaque élève doit s’acquitter des quatre postes suivants : Inscription, 1ère tranche, 2ème tranche et 3ème tranche. Un dossier est préparé pour chaque élève; les montants apparaissent « À définir » tant que l’établissement n’a pas renseigné les tarifs. Les montants ne sont pas préremplis, car ils doivent provenir des tarifs officiels de l’établissement.

Créer ou configurer le dossier d’un élève

Depuis la liste de la classe, cliquez sur + Créer en regard d’un élève sans dossier. Pour créer depuis le bouton général + Dossier de paiement :

  1. Choisissez l’élève dans Nouveau dossier de paiement. Les élèves sans dossier sont proposés en premier.
  2. Cliquez sur Créer.
  3. Le détail du dossier s’ouvre avec les quatre lignes obligatoires.

Pour définir les tarifs, cliquez sur + Configurer les 4 frais obligatoires, saisissez un montant positif pour chacun, puis cliquez sur Enregistrer les quatre montants. Pour les modifier plus tard, utilisez ✏️ Modifier les montants.

Enregistrer un versement pour une ligne

  1. Cliquez sur + Enregistrer un paiement.
  2. Dans Frais à régler, choisissez Inscription ou la tranche concernée. Le reste de chaque ligne est indiqué dans la liste.
  3. Le montant est prérempli avec le solde de la ligne; vous pouvez le réduire pour enregistrer un paiement partiel.
  4. Choisissez le mode : Espèces, Mobile Money, Virement ou Chèque.
  5. Vérifiez ou modifiez la date proposée.
  6. Cliquez sur Enregistrer le versement.

Le versement ne peut pas dépasser le reste de la ligne choisie. Le numéro de reçu est créé automatiquement, le montant payé sur la ligne est recalculé et le reçu indique le frais concerné.

Comprendre les dossiers anciens

Les anciennes lignes génériques, par exemple « Scolarité », restent visibles avec l’indication Ancienne ligne. Les anciens versements sans tranche gardent la mention Ancien versement non ventilé; ils restent inclus dans le total payé, mais ne sont pas affectés à l’une des quatre lignes par supposition.

Avant que les quatre montants soient configurés, les montants historiques restent visibles dans les totaux provisoires. Après configuration complète, les anciennes lignes génériques sont exclues du nouveau montant à verser pour éviter le double comptage; elles restent affichées comme historique à vérifier.

Factures, reçus, relances et suppressions

  • 🧾 près d’une transaction télécharge le reçu PDF correspondant.
  • 🖨️ Facture télécharge une facture récapitulant frais, total dû, payé et reste.
  • 📩 Relance affiche une confirmation visuelle; elle n’envoie pas de message réel au parent.
  • 🗑️ dans la liste des dossiers demande confirmation avant suppression du dossier.
Contrôle financier : vérifiez le nom, l’année, le montant, la date et le mode de paiement. Dans l’écran actuel, la fenêtre de détail peut afficher le texte parasite « renderView(); » au-dessus de la liste des transactions. Les lignes de versement n’ont pas de commande de modification/suppression individuelle.
Chapitre 13

Créer et imprimer des documents

  1. Ouvrez Documents et choisissez l’élève dans le filtre pour consulter ses documents.
  2. Cliquez sur + Générer un document.
  3. Choisissez l’élève et le type de document : certificat de scolarité, attestation de réussite, relevé de notes, justificatif d’absence ou document administratif.
  4. Saisissez un titre si nécessaire, puis ajoutez les observations utiles.
  5. Cliquez sur Générer. Le document est enregistré et la fenêtre d’impression s’ouvre.
  6. Dans la liste, cliquez sur 🖨️ pour imprimer, ⬇️ PDF pour télécharger ou 🗑️ pour supprimer après confirmation.

Le titre reprend le type du document s’il est laissé vide. Les relevés regroupent les notes de l’élève sans filtre de période. Les certificats et attestations utilisent un texte prérempli : relisez toutes les informations avant remise. La génération ne vérifie pas automatiquement que l’élève remplit les conditions du document.

Si la fenêtre d’impression ne s’ouvre pas, autorisez les fenêtres contextuelles pour le site puis relancez l’action. Le module ne propose pas de bouton de modification d’un document déjà enregistré.

Chapitre 14

Portail Parents : contenu et disponibilité

Le portail est conçu pour regrouper les informations d’un élève : notes, absences, emploi du temps, paiements et documents. Le tableau de bord prévoit aussi un espace de messages.

  • Un parent ayant plusieurs enfants liés peut choisir l’enfant; avec un seul enfant, le choix est verrouillé.
  • Un compte élève est associé à son propre dossier.
  • Les rôles autorisés côté établissement peuvent utiliser le sélecteur « Se connecter en tant que parent de » pour consulter un espace élève; ce sélecteur ne crée pas une vraie session parent.
  • Le bouton 📄 Voir le bulletin ouvre la page générale Bulletins.
  • La zone de messages indique actuellement qu’aucun nouveau message n’est disponible.
Disponibilité actuelle : les parents et élèves ne peuvent pas encore ouvrir une session avec le formulaire publié. Le portail ne doit pas être annoncé aux familles comme un accès actif.
Chapitre 15

Créer les comptes et comprendre les droits

Lire la matrice

La page Utilisateurs présente les droits par module pour Administrateur, Directeur, Administration, Enseignant, Parent et Élève, puis affiche la liste des comptes existants.

Créer un compte

  1. Cliquez sur + Nouveau compte.
  2. Saisissez le nom d’utilisateur, le mot de passe et le nom complet.
  3. Choisissez le rôle et indiquez si le compte est actif ou désactivé.
  4. Pour un enseignant, associez la fiche enseignant; pour un élève, associez la fiche élève; pour un parent, associez un ou plusieurs enfants.
  5. Cliquez sur 💾 Enregistrer.

Nom d’utilisateur et mot de passe sont obligatoires; le nom d’utilisateur doit être unique. Les rôles Enseignant, Élève et Parent exigent une association. ✏️ modifie un compte et 🗑️ le supprime après confirmation. Le compte actuellement connecté ne peut pas se supprimer lui-même.

Important : la matrice liste plusieurs rôles, mais l’accès actuellement publié ne permet que la connexion administrateur. Un compte non administrateur créé ici ne donne pas encore accès à l’application.
Chapitre 16

Régler l’établissement et la période

  1. Ouvrez Paramètres.
  2. Vérifiez ou modifiez Nom de l’établissement.
  3. Saisissez l’Année scolaire dans le format utilisé par l’établissement.
  4. Choisissez la Période en cours parmi Trimestre 1, Trimestre 2 ou Trimestre 3.
  5. Pour changer le logo, cliquez sur le sélecteur de fichier et choisissez une image PNG, JPEG ou WebP. Vérifiez l’aperçu.
  6. Cliquez sur 💾 Enregistrer.
  7. Vérifiez que l’année et le trimestre affichés dans la barre supérieure correspondent au réglage.

Cette page ne comporte pas de commande visible pour retirer le logo déjà enregistré ni de bouton de réinitialisation des données.

Chapitre 17

Bonnes pratiques de travail

Avant une saisie

  • Confirmez l’établissement, l’année scolaire, la classe et, pour les notes, le trimestre et la séquence.
  • Utilisez le matricule pour distinguer deux élèves portant des noms proches.
  • Vérifiez que matière et coefficient correspondent à la classe.

Après un import ou une saisie en lot

  • Comparez quelques lignes avec le document source, notamment les premières et dernières lignes.
  • Vérifiez les lignes rejetées, les élèves non reconnus et les champs laissés vides.
  • Pour un import de notes, contrôlez les catégories et le barème; pour un import de paiements, rapprochez payé, dû et reste.

Avant de remettre un document

  • Prévisualisez le bulletin ou le document.
  • Vérifiez nom, matricule, classe, année et période.
  • Ne remettez pas une attestation sans confirmer vous-même que la situation de l’élève est correcte.

Avant une suppression

Vérifiez le nom et le contenu avant de confirmer. Une suppression de classe laisse les élèves sans classe; la suppression d’un type d’évaluation peut supprimer toutes les notes de ce type dans toutes les classes.
